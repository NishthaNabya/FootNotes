Make your first memory

  1. 1

    Install the FootNotes extension from the Chrome Web Store, or load the release build locally.

  2. 2

    On X, bookmark a post. Everywhere else, right-click → Save to FootNotes.

  3. 3

    Recall it later. Press ⌘⇧O anywhere to search your memories in plain language.
